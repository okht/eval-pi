- 提交「有问题」「无问题」「不确定」与未判断项的混合批次，明确的人工判断保留，其余项进入 Agent 待核查状态。

## 报告排版

阶段报告与最终报告均按 A4 三页排版，使用本地嵌入的静态中文字体。已渲染检查中文、结论、图表、代表案例、方法和附录内容。正文保留重点案例，完整逐次结果与 Trace 单独交付。

## 边界

- 自然语言输入目前通过有限的演示指令匹配响应。
- 文件选择只展示文件名，不解析本地项目或飞书文档。
- 新建评测入口用于展示开始任务的交互，当前仅有一个客服示例项目。
- 自动调优、回归、盲测及费用为模拟过程。
- 报告中的相对附录链接需要报告与附录位于同一目录；部分 PDF 阅读器可能需要按文件名手动打开附录。
